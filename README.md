# 评论工作台 · Comment Workbench

**一个浏览器扩展，一个本机应用。** 在微博、B 站、抖音、知乎或小红书的作品详情页点击「开始采集」，把标题与已加载的评论放进自己的样本库。可以只在插件中整理、导出，也可以通过本机端口发送到分析工作台。

`Chrome MV3` · `Python / Flask` · `SQLite` · `简体中文`

## 🧭 支持哪些页面？

| 当前标签页 | 标题来源 | 使用方式 |
| --- | --- | --- |
| 微博桌面 `weibo.com/用户ID/博文ID` | 原帖正文首行（最多 120 字） | 打开一条微博的正文及评论，不在首页或搜索列表启动 |
| B 站桌面 `www.bilibili.com/video/BV…` 或 `/video/av…` | 视频标题 | 读取视频评论和已展开的楼中楼；不采弹幕、动态或直播聊天 |
| 抖音视频详情、可识别的播放弹层 | 当前视频描述或标题 | 单作品采集；另保留原有抖音专题批次 |
| 知乎专栏 `zhuanlan.zhihu.com/p/…` | 文章标题 | 展开文章评论，点击插件开始 |
| 知乎回答 `www.zhihu.com/question/…/answer/…` | 所属问题标题 | 在具体回答的详情页展开评论 |
| 小红书笔记 `www.xiaohongshu.com` | 笔记标题；无标题时取正文首行，纯媒体记为「无标题笔记」 | 点开一篇笔记再采集，可读取已展开的回复 |

小红书支持 `/explore/笔记ID`、`/search_result/笔记ID` 和 `/discovery/item/笔记ID`。不同入口按同一笔记去重；分享查询参数不进入样本，规范链接不保证可从站外直接重开。不会批量遍历首页，也不会自动展开所有楼中楼。旧版用户请同时更新本机工作台和扩展，并刷新已打开的笔记标签。

插件根据网址选择模式，不需要手动切换。知乎首页、问题下的多回答列表、搜索页不作为单篇作品采集。采集上限为每个作品 **1–1000 条**；达到上限、遇到验证或评论不再加载时停止，不保证取得平台全部评论或折叠回复。只处理你有权访问、使用的内容。

知乎详情页点击「开始采集」后，扩展会尝试展开当前作品的评论区；列表底部有「下一页」或「加载更多评论」按钮时，会继续读取至设定上限。若同页其他回答已打开独立评论弹窗，请先关闭该弹窗再开始，以免无法判断评论归属。

## 🚀 第一次使用

1. **启动本机应用。** 安装 Python 3.10 或以上版本，下载并解压仓库。Windows 双击 `start.cmd`，它会在缺少依赖时调用 pip，然后打开 `http://127.0.0.1:8765`。希望隔离依赖时，可先建虚拟环境，再运行以下命令：

   ```bash
   python -m pip install -r requirements.txt
   python server.py
   ```

2. **加载扩展。** 在平时登录对应平台的 Chrome 中打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择仓库中的 **`extension` 文件夹**，然后刷新原作品页面。旧扩展仍有样本时不要先卸载；从新目录加载可能获得新的扩展 ID，旧样本不会自动迁移。
3. **连接两端。** 在工作台展开「插件配对」并复制配对码。在扩展的「打开样本整理 → 连接分析工作台」填写同一端口及配对码，点击「连接并保存」。勾选「采集后自动发送」即可在采集结束时入库。
4. **采集并核对。** 打开目标作品并展开评论区。点扩展图标，确认标题栏显示正确平台，设置上限后开始。到「样本整理」查看标题、昵称、正文和采集时间。离线时样本仍留在插件内，可在重连后点击「发送全部保留样本」。

## 🔌 数据怎么走？

```text
微博 / B 站 / 抖音 / 知乎 / 小红书当前标签页
         │ 用户点击开始，读取已渲染的标题与评论
         ▼
浏览器扩展 ─── 样本整理 / 原始 CSV
         │ 配对码 + HTTP，仅 127.0.0.1
         ▼
本机工作台 ─── SQLite → 人工复核 → 分析 CSV / 词云
```

工作台以「规范作品链接 + 评论标识」去重。重复发送不会新增同一条评论。在插件里移除样本，**不会删除此前已发送到工作台的副本**。原始 CSV 有昵称；分析 CSV 不导出昵称，但正文仍可能包含个人信息。数据库、配对码、报告和浏览器资料不应上传到公共仓库。

内置态度词典和词云分类针对原项目的 **AI 健康咨询** 研究，不是通用情感分类器。其他主题可直接用原始 CSV；「待判定」不等于中立。

## 🛠 排障

| 现象 | 检查 |
| --- | --- |
| 端口被占用或连到旧工作台 | 用 `python server.py --port 8877` 启动新实例；插件也改为 8877，并使用新实例的配对码。 |
| 插件无法连接页面 | 刷新作品标签页；知乎请打开文章或回答永久链接，而不是首页或回答列表。 |
| 找到了标题但读不到评论 | 手动展开当前作品评论，等列表出现后重试；网站改版可能需要更新选择器。 |
| 非 Windows 系统无法生成词云 | 将 `CLOUD_FONT` 设置为本机有效的中文字体文件路径。 |

## 开发与验证

`extension/` 包含采集器与本机桥接；`server.py` 负责配对和 SQLite 入库；`engine.py` 负责分析；`templates/` 与 `static/` 构成本机界面。运行数据默认写入 `local_data/`。新安装从空库开始。

```bash
python -m unittest test_analysis test_sources
python -m pip install playwright
python -m playwright install chromium
python test_link.py
python test_zhihu_flow.py
python test_sample_ui.py
python test_xhs.py
python test_weibo_bili.py
```

端到端测试用隔离的 Chromium 配置、合成页面和临时数据库，验证抖音、知乎两种作品、真实本机 HTTP、重复发送和报告导出；不读取日常浏览器的登录状态。它能检验数据链路，但不能代替对线上网站改版的验证。
